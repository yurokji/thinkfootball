# Play Store Listing - 日本語

## アプリ名
Docushot - ドキュメントスキャナー

## 短い説明 (80文字以内)
文書スキャン、OCRテキスト抽出、PDF出力。ローカル保存でプライバシー安全。

## 全体説明 (4000文字以内)
Docushotはスマートフォンを強力なドキュメントスキャナーに変えます。レシート、契約書、ノート、IDカードなどをスキャン。すべての処理はデバイス上でローカルに行われ、プライバシーが守られます。

📸 スマートドキュメントスキャン
• Google ML Kitでカメラを向けて即座にスキャン
• 自動エッジ検出で完璧なクロップ
• 複数ページを1つのドキュメントにスキャン

✂️ クロップ＆回転
• 4点パースペクティブ補正で斜めの文書も完璧に
• 自由回転で正確な位置合わせ
• 保存されたコーナー位置でいつでも再編集

🎨 フィルター＆補正
• マジックカラー: きれいで読みやすいスキャンに自動補正
• 白黒: クラシックなドキュメントスタイル
• 明るく: 暗いスキャンを明るく
• 手動の明るさ＆コントラスト調整

📝 OCRテキスト認識
• スキャンしたドキュメントからテキストを抽出
• 5つの文字体系に対応: 日本語、英語、韓国語、中国語、デーバナーガリー
• 抽出したテキストをクリップボードに即コピー

📄 柔軟なエクスポート
• PDF出力（A4、自動方向）
• 個別画像の共有
• ZIP出力（プレミアム）

📁 ドキュメント管理
• タイトルでドキュメントを整理
• ドラッグ＆ドロップでページ順序変更
• タイトルまたはOCRテキストで検索
• 複数ドキュメントの結合（プレミアム）
• 一括操作（プレミアム）

💾 バックアップ＆復元
• ZIPファイルでフルバックアップ作成
• ローカルバックアップから復元（プレミアム）

🔒 プライバシー保護
• すべての処理はデバイス上でローカルに
• クラウドアップロードなし、アカウント登録不要
• アナリティクスやトラッキングなし

⭐ プレミアム機能
• 無制限OCR（無料: 1日3回）
• すべてのフィルター＆調整
• ZIP出力＆一括操作
• ドキュメント結合
• バックアップ＆復元

英語、韓国語、日本語に対応しています。
